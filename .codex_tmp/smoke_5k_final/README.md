# 5k Commit Patch-Aware Javadoc Updating Dataset

This directory is the commit-level merged view for the Patch-Aware Javadoc
Updating task.

Input fields for each change are `issue_summary`, `code_before`, `code_after`,
and `javadoc_before`. The target field is `javadoc_after`.

The target is **at least 2571 unique valid commits**, where a
unique commit is `project_slug + commit_hash`. Changes are additional
statistics and are not the stop condition.

## Sources

- Effective baseline: `final_dataset_merged_no_commit_cap`
- Legacy capped merged dataset preserved for audit: `final_dataset_merged`
- New continuation candidates: `final_dataset_continuation_to_5k_commits`

## Cleaning

Changes are deduplicated globally by exact content fingerprint over
`code_before`, `code_after`, `javadoc_before`, and `javadoc_after`. Commits
whose changes are all removed are removed from the final commit count. Weak
issue summaries are not generated by a model; unresolved weak summaries are
excluded.

## Max-3 Audit

The active baseline is the no-cap merged dataset. It already contains commits
with more than 3 changes, and this continuation flow does not truncate changes
per commit.
